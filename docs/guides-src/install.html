Ledger 手机记账
新用户安装指南

付款后轻点 iPhone 背面两下，自动截图、读出金额和商家，帮你记一笔。

完全免费 · 资料只属于你自己 · 大约 15 分钟 · 版本 v1.1 · 2026-10-28

你会得到什么

  • 敲两下自动记账：一张截图记一笔，或一张活动列表截图记一整天，不会重复。
  • 钱进来也记：朋友转钱给你、退款、薪水，会记成收入，可以设定一律存进某个账户。
  • 认得常见商家（McDonald's、Petronas、Grab…），分成 衣、食、住、行，也可以自己加分类。
  • 拿不准就问你：用哪个账户付的、这笔算哪一类，点一下就好。
  • 外币自动换成马币（USD、USDT、SGD…），用消费当天的汇率。
  • 账户、投资、负债各自的进出记录；收入可以按比例分进各个账户；储蓄目标可以绑定账户。
  • 统计：每个分类花多少、星期几花得最多。
  • 6 位密码进入，不用邮箱登录；每天自动更新到最新版本。

开始之前

你需要：一台 iPhone，和大约 15 分钟。

第 1–3 步（注册和安装）用电脑做比较顺，只有手机也可以。第 4 步开始在 iPhone 上做。
更方便的做法：用手机打开 eesontong666-lab.github.io/ledger，那里有一样的步骤，一页一步，每一步都有按钮可以直接点。

安装步骤

1

注册 GitHub（免费）

打开 GitHub 注册

填邮箱、设密码、取一个用户名，再到邮箱收验证码填进去。看到 GitHub 首页就完成了。把用户名记下来，以后更新会用到。已经有账号就跳过。

2

注册 Vercel（免费）

打开 Vercel 注册

  1. 方案选 Hobby（免费的那个），填名字。
  2. 点 Continue with GitHub，再点绿色的 Authorize Vercel。
  3. 如果要你验证手机号码，照做。
⚠️ 一定要选 Continue with GitHub，不要用邮箱注册，下一步才接得上。
3

安装你的 App

开始安装

在打开的页面照顺序做三件事：

  1. Create Git Repository：名字不用改，点 Create。如果先要你安装 GitHub 权限，点 Install，选 All repositories。
  2. Add Supabase（存账本的数据库）：点 Add → 同意条款 → Region 选 Singapore → Plan 选 Free → Create。
  3. Deploy：点 Deploy，等大约 2 分钟，看到彩带和 Congratulations 就好了。
4

找到你的 App 网址

点 Continue to Dashboard，在 Domains 下面那个以 .vercel.app 结尾的就是你的网址（例如 my-ledger-abc.vercel.app）。发到自己的 WhatsApp 或备忘录。

⚠️ 这个网址是你账本的入口，不要发给别人。
5

设置 6 位密码（装好后马上做）

在 iPhone 用 Safari 打开你的网址，输入你想要的 6 个数字，再输入一次确认。

第一个设密码的人就是账本的主人。以后打开 App 只要这 6 个数字；连错 5 次会锁 15 分钟。

6

加到主屏幕

在 Safari 点底部的 分享（方框加向上箭头）→ 添加到主屏幕 → 添加。主屏幕会出现一个绿色图标。

7

加上你的银行账户

打开 App → 底部 👛 账户 → ＋ 添加账户，填名称和现在的余额。有几个加几个；投资、信用卡欠款也在这里加。

8

开启「敲两下自动记账」

这一步用 Safari 打开你的网址来做（不要用主屏幕图标）。App 底部 ⚙️ 设置 → 📲 截图记账，右上角可以切换 中 / EN。

  1. ① 生成专属链接 → 点 复制（只显示一次）。
  2. ② 下载快捷指令 → 下载 → 点开下载好的文件 → 长按输入框 粘贴 → 添加快捷指令。
  3. ③ iPhone 设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下，选 Ledger Screenshot。

English iPhone: Settings → Accessibility → Touch → Back Tap → Double Tap.

9

试一笔

打开银行 App 任何一笔付款成功或交易详情的画面，轻点手机背面两下。第一次会问几次权限，都选 始终允许。几秒后会出现「✅ 已记账 RM… · 商家」。

可能会再弹出两个选单：用哪个账户付的？和这笔算哪一类？，各点一下就好。按取消也没关系，App 首页会留着等你补上。

别人转钱给你的画面也一样敲两下，会记成收入。想让这种进账一律存进某个账户：设置 → 📲 截图记账 →「进账存到哪个账户」。
