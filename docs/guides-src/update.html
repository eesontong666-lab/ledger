Ledger 手机记账
更新指南

给已经装好的人：更新到最新版本，账本资料全部保留。

只做一次 · 大约 5 分钟 · 之后每天自动更新 · 版本 v1.1 · 2026-10-28

更新后什么都不会变

  • 账本里的交易、账户、目标、分类：全部保留
  • App 网址、6 位密码：不变
  • 已经装好的快捷指令：照样能用

这次更新有什么新东西

  • 一张截图记一整天：截银行的活动列表，里面每一笔支出都会记下，已经记过的自动跳过。
  • 拿不准就问你：截图后弹出选单问「用哪个账户付的？」「这笔算哪一类？」。
  • 认得常见商家（McDonald's、Petronas、BHP、Grab…），改过一次分类就记住。
  • 自己加分类（设置 → 🏷️ 分类），每一笔的金额、商家、日期、账户都能改。
  • 外币换成马币（USD、USDT、SGD…），用消费当天的汇率。
  • 星期几花得最多：统计页的消费习惯。
  • 钱进来也记：别人转钱给你、退款的截图会记成收入，可以设定一律存进某个账户。
  • 自动更新：做完这一次，以后每天自己更新。

更新步骤

最方便的做法：用手机打开 eesontong666-lab.github.io/ledger/update.html，按下面一样的三步点就好，按钮都帮你准备好了。

1

打开更新页，填你的 GitHub 用户名

打开更新页

填安装时注册的 GitHub 用户名。仓库名字没改过的话，保持 my-ledger。

不记得用户名：登录 github.com，点右上角头像，最上面那一行就是。

2

加上自动更新

在更新页点 「打开 GitHub」，内容已经帮你填好，什么都不用改：

  1. 点右上角绿色的 Commit changes…
  2. 弹出的框里再点一次 Commit changes。

如果 GitHub 说文件已经存在，表示你已经有自动更新了，直接做第 3 步。

3

马上更新一次

在更新页点 「打开更新页面」：

  1. 点右边的 Run workflow，再点绿色的 Run workflow。
  2. 等 3–4 分钟，打开你的 App。在 设置 里看到 🔄 版本与更新，就是更新好了。

不做这一步也可以，今晚会自己更新。

4

（建议）换上新的快捷指令

想用「弹出选单问账户和分类」，要换一次快捷指令。旧的照样能记账，只是不会弹选单。

  1. 用 Safari 打开你的 App → 设置 → 📲 截图记账。
  2. ① 重新生成专属链接 → 复制。
  3. ② 下载快捷指令 → 点开文件 → 粘贴链接 → 添加。
  4. iPhone 设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下，改选新的 Ledger Screenshot。

在同一页「截图记到哪个账户」选 每次都问我，记账后就会问你用哪个账户付的。
