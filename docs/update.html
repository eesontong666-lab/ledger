更新你的记账 App

只做这一次。之后有新功能，你的 App 每天会自己更新。

  • 账本里的资料全部保留
  • 网址、6 位密码不变
  • 已经装好的快捷指令照样能用

Update your bookkeeping app

You do this once. After that your app updates itself every day when there is something new.

  • Everything in your ledger is kept
  • Your address and 6-digit passcode stay the same
  • The shortcut you already installed keeps working

① 填你的 GitHub 用户名

① Enter your GitHub username

不记得用户名？打开 github.com 登录，点右上角的头像，最上面那一行就是。

Forgot it? Sign in at github.com and tap your picture at the top right; it is the first line.

② 加上自动更新

② Add automatic updates

打开 GitHub ↗Open GitHub ↗
  1. 页面里的内容已经帮你填好了，什么都不用改。
  2. The page is already filled in. Change nothing.
  3. 点右上角绿色的 Commit changes…
  4. Tap the green Commit changes… at the top right.
  5. 在弹出的框里再点一次绿色的 Commit changes。
  6. In the box that appears, tap the green Commit changes again.

如果 GitHub 说这个文件已经存在，表示你已经有自动更新了，直接做第 ③ 步。

If GitHub says the file already exists, you already have automatic updates. Go straight to step ③.

③ 马上更新一次

③ Update right now

打开更新页面 ↗Open the update page ↗
  1. 点右边的 Run workflow，再点绿色的 Run workflow。
  2. Tap Run workflow on the right, then the green Run workflow.
  3. 等 3–4 分钟，打开你的 App。在 设置 里看到 🔄 版本与更新，就是更新好了。
  4. Wait 3–4 minutes and open your app. When 设置 (Settings) shows 🔄 版本与更新, the update is done.

不做这一步也可以：今晚它会自己更新。

You can skip this step: it will update by itself tonight.
